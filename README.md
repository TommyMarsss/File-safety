# 安全文件上传服务

一个真实前后端联调的文件上传服务，演示服务端内容安全校验。**仅使用 Python 标准库**（不依赖 python-magic 等第三方库），前端为原生 HTML/CSS/JavaScript，通过真实 `multipart/form-data` 与后端交互。

## 运行

```bash
python3 server.py        # 默认监听 http://127.0.0.1:8000
python3 server.py 9000   # 指定端口
```

浏览器打开 `http://127.0.0.1:8000`，可以：

1. 选择本地文件上传；
2. 点击预置样本按钮（合法 PNG/ZIP、伪造扩展名的可执行文件、路径穿越文件名、ZIP 压缩炸弹、含符号链接的 ZIP、Zip Slip 等），样本由服务端实时生成，前端拿到字节后作为文件真实上传；
3. 实时查看后端的接受/拒绝判定与具体原因。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：合法文件正常上传、魔数不匹配被拒绝、路径穿越文件名被拒绝、压缩炸弹在检测阶段（而非解压时）被拒绝、符号链接 ZIP 被拒绝、Zip Slip 被拒绝、嵌套压缩包被拒绝、静态目录穿越被拦截、超大请求 413 等 33 个用例（单元 + 真实 HTTP 集成）。

## 校验策略

上传处理管线（`security.validate_upload`），任一环节失败即拒绝，全部通过才落盘：

1. **大小限制**：空文件拒绝；超过 25 MB 拒绝。HTTP 层在读请求体之前先按 `Content-Length` 拒绝超大请求（413）。
2. **文件名清洗**（`check_filename`）：策略是「拒绝」而非「尝试修复」。含 `/`、`\`、`..` 片段、绝对路径（`/...`、`C:...`）、NUL 字节、隐藏文件（`.` 开头）、白名单外字符的一律拒绝。
3. **可执行文件拦截**：按魔数识别 PE（`MZ`）、ELF（`\x7fELF`）、Mach-O（含 universal）、shebang 脚本，直接拒绝。
4. **真实类型识别**（`detect_file_type`）：按文件头魔数识别 PNG / JPEG / GIF / BMP / WebP / PDF / ZIP，**完全忽略**用户提交的文件名后缀与 `Content-Type`。
5. **扩展名一致性**：扩展名声称的类型与魔数识别的真实类型不一致即拒绝（例如内容是 PNG 却叫 `document.pdf`）。
6. **ZIP 安全分析**（`analyze_zip`）：**只读中央目录元数据，不解压任何内容**，全部在写盘前完成：
   - 条目数 ≤ 200；
   - 解压后总大小 ≤ 100 MB、单条目 ≤ 50 MB（元数据声明值，炸弹在此现形）；
   - 单条目压缩比 ≤ 100:1（压缩后 < 1 KB 的条目豁免，避免小文本误伤）；
   - 符号链接条目（`external_attr` 中的 Unix st_mode）拒绝；
   - 成员名含 `..`、绝对路径、NUL 字节拒绝（Zip Slip）；
   - 嵌套压缩包拒绝（防递归炸弹）。

### 存储安全

- 落盘文件名完全由服务端生成（`uuid4 + 白名单扩展名`），**用户输入不影响存储路径**。
- 通过全部检查的 ZIP 解压到 `uploads/extracted/<uuid>/` 时仍做二次防护：成员名拍平为 basename、校验 `realpath` 必须位于目标目录内、同名去重。
- 静态资源目录同样做 `..` 与 realpath  containment 检查。
- 所有响应带 `X-Content-Type-Options: nosniff`。

## 已知局限

- **魔数只验证文件头**：一个带合法 PNG 头、尾部拼接恶意负载的 polyglot 文件会通过类型检查。完整方案需要解析文件结构（如用 Pillow 解码验证图片可解析），但这超出标准库能力。
- **类型白名单较窄**：仅支持 PNG/JPEG/GIF/BMP/WebP/PDF/ZIP，且只覆盖常见魔数；不像 libmagic 那样有数千条规则与偏移匹配。
- **压缩比阈值是启发式**：100:1 可能误伤极端可压缩的合法文件（如大尺寸纯色图导出的文本数据），也可能放过 99:1 的炸弹；需配合总大小上限共同生效。
- **ZIP 元数据可撒谎**：中央目录声明的解压大小可能被伪造（与实际解压结果不符）。本实现在解压时未做流式累计截断；生产环境应在解压写入时实时累计字节数、超限即中断删除。
- **仅支持 ZIP**：tar/tar.gz（tarfile 的 `filter="data"`）、7z、rar 未覆盖。
- **无病毒扫描**：内容级恶意载荷（宏、脚本嵌入）需要专业 AV 引擎。
- **单进程内存解析**：请求体整体读入内存，25 MB 上限即内存上限；更大文件需要流式 multipart 解析。
- **无认证与速率限制**：演示服务未实现上传配额、鉴权、CSRF 防护，仅监听 127.0.0.1。

## 目录结构

```
server.py            HTTP 服务（路由、multipart 解析、落盘）
security.py          校验核心（魔数、文件名、ZIP 分析、安全解压）
samples.py           预置样本生成器（合法 + 恶意）
static/              原生前端（index.html / app.js / style.css）
tests/               单元测试 + 真实 HTTP 集成测试
uploads/             上传存储目录（运行时生成）
```
